Build from source

  1. Install Visual Studio 2026 with .NET Desktop Development and .NET 10.
  2. Open HazzKaraokeHoster.sln.
  3. Select Release and x64.
  4. Choose Rebuild Solution.
  5. Run RELEASE\HazzKaraokeHoster\Hazz Karaoke Hoster.exe.

Release checks

Visual Studio 2026 Release x64 build passed. The application version is 1.0.0.0 and the release folder contains exactly one executable. The source and portable ZIP files are integrity-checked before upload. SHA-256 values are listed on the GitHub release page.

Included: Music video overlays

In Audience Display Settings, use Show During Music Videos to keep the permanent logo, rotation / venue scroller, next singers or Kamikaze message visible. Each has its own checkbox. Unchecked overlays are hidden; checked overlays follow their normal settings. Choices apply live and are saved.

Also included

Separate player sound devices, adjustable RMS audio normalization, next-track standby cueing, pre-show file checks, automatic backups and music-position recovery. Sound Devices and Normalize Audio are directly accessible from the top menu.

Automated checks passed. Physical multi-device and multi-hour playback testing remain outstanding.
