# Hazz Karaoke Hoster v2.20

Made For KJ/DJ's By A KJ/DJ

v2.20 includes a ready-to-use Halloween audience bezel sample in every portable and optional single-EXE download. The existing music effects, saved singer-list widths, Singer Database Manager, crossfade presets, Library Health Centre and all earlier features remain included.

## Halloween audience bezel sample

The included `Templates/Hazz_Audience_Bezel_Halloween_1920x1080.png` is an exact 1920 × 1080 transparent PNG. Its black-and-purple Halloween border includes pumpkins, bats, cobwebs and haunted houses, while its large centre window remains fully transparent.

1. Extract the complete Hazz download.
2. Open **DISPLAY** in Hazz.
3. Tick **Audience bezel / event frame**.
4. Choose `Templates/Hazz_Audience_Bezel_Halloween_1920x1080.png`.
5. Keep the bezel enabled while using karaoke, CD+G, music video, slideshow, singer information or scrolling messages.

Hazz automatically detects the transparent viewing window. It fits the complete audience display into that window, including singer details and both scrollers. The bezel is always the top layer, so the artwork is never covered by video or text. There are no manual edge-position controls to set.

The editable `Hazz_Audience_Bezel_Template_1920x1080.psd` and the template guide remain in the same `Templates` folder for making your own venue or event frames.

## Installation

Close older Hazz versions, extract the complete v2.20 Windows ZIP into a new folder and run **Hazz Karaoke Hoster.exe**. The header should show **v2.20**. Existing libraries, singers, venue profiles and audience settings remain in their normal locations.

## Validation

The packaged bezel is verified as a 1920 × 1080 PNG with a transparent centre. The release build and portable package checks cover the app, included template files, VLC runtime and SQLite runtime. Test your actual audience display before a live show, particularly when using a custom frame designed for a different aspect ratio.
