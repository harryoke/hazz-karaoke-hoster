# v2.20.4 FOLDERS - Manual crossfade

In two-deck mode, press Play on either deck, then Play on the other. The second deck starts muted while the first continues. Drag the slider: full left plays only Deck 1, full right plays only Deck 2, and positions in between blend them. The slider changes gains without pausing the silent deck. Moving it takes over from an automatic fade and switches Auto Crossfade off. Tick Auto Crossfade again to return to automatic operation; a deck that is already running is not restarted by automation. Single Deck mode leaves Deck 2 as a side list.

Verified crossfader gains, manual takeover, independent track completion, layout at five sizes, and the packaged runtime. The checks did not exercise a physical drag or listen to the laptop's output.
