# Hazz Karaoke Hoster v1.74.5 — Singer rotation standing

v1.74.5 improves the host singer list so the current karaoke rotation is easier to read at a glance.

## Singer rotation display

- A new **Rotation** column shows the standing of each ready singer as **1 / N, 2 / N, 3 / N**, etc.
- The first ready singer is clearly marked **NEXT** and the whole row is highlighted.
- Singers on **HOLD** remain visible but are not counted in the ready rotation total.
- Singers with no queued karaoke song remain visible but are not counted until they have a song.
- The standing follows Hazz's actual live queue order, including manual ordering and Automatic Fair Rotation.
- When a singer starts, Hazz's existing handoff still moves them to the bottom; the new NEXT highlight then moves to the new first ready singer automatically.
- Existing audience-screen rotation behaviour is unchanged.

All v1.74.4 deck-to-deck music dragging, v1.74.3 duration/Search Columns fixes, v1.74.2 BPM MP3-tag fixes and earlier v1.74.x features remain included.
