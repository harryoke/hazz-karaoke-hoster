# Hazz Virtual Folders

Open **LIBRARY > Browse Library**. The left side of the Library Browser contains **VIRTUAL FOLDERS**.

## Create folders

1. Press **NEW FOLDER**.
2. Enter a useful category such as `80s`, `Rock`, `Jingles`, `Party` or `Slow Songs`.
3. To organise a category further, select it and press **NEW SUBFOLDER**.

## Add tracks

- Drag a track from the library list onto a folder; or
- select one or several tracks, press **ADD SELECTED TO FOLDER**, then choose the destination.

The same track can appear in several virtual folders. Hazz stores links to the library entry;
it does not copy, rename or move the actual karaoke, music or video file.

## Use a folder

Select a folder to display its tracks. The **KARAOKE** and **MUSIC** buttons, filter box,
sorting, paging, drag-and-drop, **ADD TO SELECTED SINGER**, and deck buttons continue to work.
Press **ALL LIBRARY TRACKS** to leave the folder and return to the complete library.

## Maintain folders

- **RENAME** changes the selected folder's name.
- **REMOVE FROM FOLDER** removes selected track links from the open folder.
- **EMPTY** removes every direct track link from the selected folder.
- **DELETE** removes the selected folder and its subfolders.

Emptying or deleting a virtual folder does not delete any media file or library track.
