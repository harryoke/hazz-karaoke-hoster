# Hazz Audience Bezel Template

The supplied `Hazz_Audience_Bezel_Template_1920x1080.psd` is a 16:9 Photoshop template. Hazz also includes `Hazz_Audience_Bezel_Halloween_1920x1080.png`, a ready-to-use 1920 × 1080 Halloween sample.

To use the sample, open **Display**, tick **Audience bezel / event frame**, choose `Hazz_Audience_Bezel_Halloween_1920x1080.png` from the included `Templates` folder, then leave the bezel enabled. The clear centre is true transparency, so Hazz automatically keeps video, singer information and scrollers inside it while the Halloween artwork remains above the display.

1. Open it in Photoshop or another PSD editor.
2. Keep your artwork outside the pink **VIDEO SAFE AREA** outline. The centre must stay fully transparent.
3. Hide or delete the pink guide layer before exporting.
4. Export as a transparent **PNG**, keeping the image at 1920 × 1080.
5. In Hazz, open **Display**, choose **Audience bezel / event frame**, then choose that PNG. Hazz automatically finds the largest transparent rectangle and fits the audience display inside it.

For a slideshow, put several transparent PNG bezels in one folder and choose **CHOOSE FOLDER**. Hazz cycles them at the selected interval.

The template has a 5% safe margin on every edge. Hazz detects this clear centre automatically, so no manual edge values are required.
