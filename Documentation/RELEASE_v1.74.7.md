# Hazz Karaoke Hoster v1.74.7 — Delete saved/imported playlists

v1.74.7 adds a safe playlist-deletion option to the Music Playlists & History window.

## Delete Playlist

- Select a playlist on the **PLAYLISTS** tab and press **DELETE PLAYLIST**.
- Hazz shows a confirmation with the playlist name and number of tracks.
- The action deletes only the selected playlist and its saved playlist entries from the Hazz database.
- **No music/video files are deleted from disk.**
- **Music History is not deleted.**
- Imported BPM Studio playlists can be recreated later by importing that BPM source again.
- The playlist list refreshes immediately after deletion.

All v1.74.6 singer-rotation standing changes and earlier v1.74.x features remain included.
