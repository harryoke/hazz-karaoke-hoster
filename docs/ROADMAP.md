# Hazz Karaoke Hoster Roadmap

## Completed foundations through v0.4
- Three-deck host layout.
- CD+G/MP3+G/ZIP playback foundation.
- Audience display, Next Singer and venue scroller.
- CD+G ±0.25 second graphics timing.
- Singer rotation and drag/drop ordering.
- Automatic Deck 1 ↔ Deck 2 crossfade with karaoke interruption/resume.
- SQLite/FTS5 library foundation and Karma import foundation.
- Self-contained Windows x64 Release EXE.

## Next engineering milestones
1. Real-time key changing without tempo change.
2. Persistent show-session recovery and singer queue auto-save.
3. Large-scale media folder scanner/importer for 2M+ records.
4. Per-track saved key and CD+G sync values.
5. More advanced music playlist editing, drag/drop and scheduling.
6. Installer, crash logging and automatic rotating database backups.
