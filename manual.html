1 Getting started

Connect the audience television or projector before opening Hazz and set Windows to extend the desktop. Keep song drives connected for the whole show. Open the supplied single EXE from the Release folder and test Windows sound, Display 2 and representative song formats.

2 The live console

Deck 1 and Deck 2 run background music. The centre Karaoke Deck controls the singer song. The Karaoke Singers List is the running order. Search switches between Karaoke, Music and Music Video. Library, Import, Display and Show contain setup commands.

Function colours

  • Green plays or confirms.
  • Red stops, removes or clears.
  • Yellow pauses or changes timing.
  • Blue loads or navigates.
  • Teal adds or saves.
  • Purple runs special actions.

3 Build the libraries

Use Import Karaoke Folders for ZIP, CDG pairs and video karaoke. Use Import Music / Video Folders for interval music and VJ video. Browse Library inspects indexed records; Rescan Watched Folders finds files added while Hazz was closed.

Supported files

Audio: MP3, WAV, WMA, M4A, AAC, FLAC, OGG, AIF and AIFF. Video: MP4, MKV, AVI, MOV, MPEG, MPG, WMV, M4V, VOB, TS, M2TS, WEBM and DIVX. Karaoke: ZIP, CDG plus companion audio, and video.

4 Import from another program

Use Import, Smart Import, Detect from File or Detect from Application Folder. Review the detected program and samples before importing. The source stays read-only.

For singer performances, choose Import Singer History. CSV, TSV, TXT, JSON, XML, SQLite, MDB, ACCDB and KDB are supported. Hazz detects common singer, song, date, key and play-count columns, links known library songs and retains unmatched history.

BPM Studio large libraries

The dedicated importer skips unchanged GRP and PLG files. Duplicate filenames use only the newest modified copy, with the larger file winning a date tie. Song indexing and virtual-folder links run in batches. Wait for the progress window to complete Reading, Indexing, Linking, Saving and Finalizing database.

5 Search and broken files

Use Karaoke search for singer requests and drag a result onto a singer or directly onto the Karaoke Deck to load it. Supported karaoke files can also be dropped from Windows Explorer. Music search supports Shift-click for a range, Ctrl-click for individual tracks, Ctrl+A or Select All for every displayed result. Music Video searches only video files in the music library and provides the same selection and deck actions. In Music or Music Video search, Space immediately plays the highlighted result; Space again stops it.

Missing or unplayable media is tagged as broken and colour-coded, with a recorded failure reason.

VJ music videos

Use Import Music / Video Folders to add video folders. Press Music Video at the top to search only those video files. A video played by Deck 1, Deck 2 or Space-bar quick play appears full-screen on the singer display. The audience copy is muted and follows play, pause, resume, seek and stop. Singer lists, scrollers, messages, backgrounds and the logo hide automatically so the video is unobstructed. Karaoke automatically takes priority.

6 Singers and requests

Type or choose a name and press Add Singer. The previous-singer picker opens with recent names and searches the full database in the background. Drag songs onto singers. Double-click a singer or use the right-click menu for Songs and History.

Drag the order, use Move Up or Move Down, or Set As Next. Hold temporarily skips a singer until release; Skip Once passes them one time. History can be searched and a previous song can be dragged or double-clicked into the active list.

7 Play karaoke

  1. Press Load Next Singer, or drop a track directly onto the Karaoke Deck.
  2. Check the singer and song.
  3. Press TV to confirm Display 2.
  4. Press the green Play button.

Pause resumes from the same point. Fade Stop lowers karaoke over 1.5 seconds, then fades the returning music in over 1.5 seconds. Key controls run from -6 to +6 semitones. CDG sync moves graphics earlier or later in 0.25-second steps. Find Alternative chooses another version; Kamikaze assigns a random song.

8 Music decks

Add files, drag Music results, or load a saved or imported playlist. Pause retains the exact position; press Pause or Play to resume. Drag the timeline slider to seek to an exact point. Stop and Shuffle affect that deck. Remove Selected removes unplayed queue entries without deleting files. Save Playlist stores the remaining queue.

Normal mode provides two decks with automatic or manual crossfade. Choose Show, Single Deck + Side List Mode to keep Deck 1 as the only player. The complete Deck 2 player is replaced by Add, Load, Save, Select All, Move, Send to Deck 1, Shuffle, Remove and Clear controls. Track order is preserved and Deck 1 advances automatically. The mode is remembered.

Starting karaoke suspends background music; Play Music starts the next scheduled track afterwards.

9 Audience display

Use Display to open, move or send the audience window full screen. TV sends it directly to Display 2 and refuses to fall back to Display 1 if that display is absent.

Configure the next four singers, optional songs, fonts, colours and position. Add a complete-rotation scroller at the top or bottom. Choose an image, GIF, muted video or a folder slideshow. Each item has a one-minute slot. Set GIF speed and choose Fit, Fill crop, Stretch or Centre. A persistent logo stays over CDG and video when enabled.

10 Show safety

New Show clears the current rotation and starts a fresh duplicate-song window. Karaoke Only Mode hides both music decks. Hazz checkpoints the rotation and unplayed music queues and can restore an interrupted show. Closing asks for confirmation and a clean shutdown releases playback resources.

11 Backup and data

Use Library, Database, Backup Database before large imports. Hazz stores its database and settings under %LOCALAPPDATA%\Hazz Karaoke Hoster. Keep the original data from other applications until the imported paths and history have been checked.

12 Troubleshooting

  • Missing file: reconnect the drive, restore the indexed path and rescan.
  • Video will not play: test it in Windows Media Player and check Windows codecs.
  • No audience picture: use Extended desktop, reopen Display and explicitly select Display 2.
  • Lyrics early or late: adjust CDG sync, not Key.
  • Cramped controls: maximise, hide preview, move splitters or enable Karaoke Only Mode.
  • Large BPM import: follow the changing phase text and wait for Import complete before starting another import.

13 Build with Visual Studio 2026

Install .NET Desktop Development and .NET 10. Open HazzKaraokeHoster.sln, choose Release and x64, then Rebuild Solution. The result is RELEASE\HazzKaraokeHoster\Hazz Karaoke Hoster.exe. BUILD-EXE.cmd produces the same self-contained release.

14 Before doors open

  • Test Display 2 and Windows audio.
  • Play a ZIP, CDG pair and video karaoke file.
  • Play one track on each music deck.
  • Confirm the audience background and scroller.
  • Check the database backup date.
  • Start New Show and load the first request.

Included: Music video overlays

In Audience Display Settings, use Show During Music Videos to keep the permanent logo, rotation / venue scroller, next singers or Kamikaze message visible. Each has its own checkbox. Unchecked overlays are hidden; checked overlays follow their normal settings. Choices apply live and are saved.

Also included

Separate player sound devices, adjustable RMS audio normalization, next-track standby cueing, pre-show file checks, automatic backups and music-position recovery. Sound Devices and Normalize Audio are directly accessible from the top menu.

Automated checks passed. Physical multi-device and multi-hour playback testing remain outstanding.
